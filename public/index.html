    Codex 账户
    加载中…
    第二个账号 · 设备码登录
    在独立 CODEX_HOME（data/codex-profiles/）里登录，不影响 Codex App 当前账号；登录成功后自动续期。取消或超时会注销这个托管号的登录会话，需要重新登录。
    1. 打开 https://auth.openai.com/codex/device
    2. 输入一次性码

    切换 Codex 账号后，面板会自动把当前登录态归档到 data/codex-accounts/（明文、仅本机；可在 data/config.json 设 autoArchive: false 关闭），旧账号的额度卡片会保留。也可以手动粘贴其他机器上的 auth.json 内容添加。扫描只检查是否存在 access_token，不显示令牌内容。设备码登录的托管账号写在 data/codex-profiles/，带 managed: true 的账号会自动续期（不影响当前登录账号）。

    OpenCode Go 订阅
    加载中…

    每个订阅 = 一把 Go Key + 一个 DSH 路由（opencode-go 对应「谷歌」、opencode-go2 对应「Github」）。面板按路由拆出各订阅的 Token，顶部 OpenCode Go 统计为所有订阅之和。

    DeepSeek 平台登录态（消费 / 余额）

    打开 platform.deepseek.com → F12 → Application → Local Storage → userToken，复制值粘贴到这里。仅存本机，用于读取官方余额、累计消费和近 30 天用量（私有接口，可能随网站改版失效）。

    CSV 每行 date,tokens[,费用]；JSON 支持 [{"date":"2026-08-01","tokens":1200000,"costCny":0.31}]。导入按「取较大值」合并进 data/daily-history.json（先备份 .bak），不会覆盖更大的历史值。

    欢迎使用 QUOTA BOARD

    你的额度，一眼看清。

    把常用平台的额度和用量放在一起，打开页面就能查看。

    第一步 · 选择来源

    从你正在使用的平台开始

    选择一个来源，结束介绍后会为你打开对应的设置。暂时不选也没关系。

    只需配置你用到的来源；其他来源可以以后再添加。

    第二步 · 认识面板

    开始之后，看这三个地方

    从整体到细节，慢慢探索就好。

    01

    看总览查看累计用量和热力图。

    02

    看趋势查看每天用量、累计变化和各来源占比。

    03

    管理来源在「管理」中查看额度、添加来源或重开使用介绍。

    配置和凭据保存在本机；查询时会连接你使用的平台。

    额度一念 · 本机额度与用量面板

    导入官网用量

    在 OpenCode 官网「Activity → Usage」导出工作区 CSV。可选最近 90 天覆盖完整账期。

    默认从第一个完整 UTC 日算起。按官网权重快照折算，账期内权重变化和超额用量会影响结果。数据保存在当前浏览器。
