Codex 账户
加载中…

切换 Codex 账号后，面板会自动把当前登录态归档到 data/codex-accounts/（明文、仅本机；可在 data/config.json 设 autoArchive: false 关闭），旧账号的额度卡片会保留。也可以手动粘贴其他机器上的 auth.json 内容添加。扫描只检查是否存在 access_token，不显示令牌内容。

OpenCode Go 订阅
加载中…

每个订阅 = 一把 Go Key + 一个 DSH 路由（opencode-go 对应「谷歌」、opencode-go2 对应「Github」）。面板按路由拆出各订阅的 Token，顶部 OpenCode Go 统计为所有订阅之和。

DeepSeek 平台登录态（消费 / 余额）

打开 platform.deepseek.com → F12 → Application → Local Storage → userToken，复制值粘贴到这里。仅存本机，用于读取官方余额、累计消费和近 30 天用量（私有接口，可能随网站改版失效）。

导入历史用量（补齐数据源看不到的旧数据）

CSV 每行 date,tokens[,费用]；JSON 支持 [{"date":"2026-08-01","tokens":1200000,"costCny":0.31}]。导入按「取较大值」合并进 data/daily-history.json（先备份 .bak），不会覆盖更大的历史值。

说明
  • Codex 额度读取本机 ~/.codex/auth.json 的 OAuth 登录态，调用官方 /backend-api/wham/usage（只读，不会写回登录态）。是否需要代理取决于网络环境；可参考使用手册配置。
  • OpenCode Go 读取 https://opencode.ai/zen/go/v1/usage，显示 5 小时 / 每周 / 每月三个窗口。
  • 中转站余额通过站点接口查询；New API 默认 1 USD = 500000 quota，不同站点可在添加时改系数。

欢迎使用 额度一念

你的额度，一眼看清。

把常用平台的额度和用量放在一起，打开页面就能查看。

第一步 · 选择来源

从你正在使用的平台开始

选择一个来源，结束介绍后会为你打开对应的设置。暂时不选也没关系。

只需配置你用到的来源；其他来源可以以后再添加。

第二步 · 认识面板

开始之后，看这三个地方

从整体到细节，慢慢探索就好。

01

看总览在页面上方查看汇总和每日趋势。

02

看额度在额度卡片中查看各来源的状态和剩余额度。

03

调整设置在页面下方添加来源；在「说明」中可重新打开介绍。

配置和凭据保存在本机；查询时会连接你使用的平台。
