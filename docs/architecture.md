# 架构

额度一念由本机 HTTP 服务和静态前端组成。服务只监听 `127.0.0.1`；浏览器通过本机 API 获取汇总、用量、配置与历史数据。

- `server.mjs`：路由、请求校验、缓存、后台归档及静态文件服务。
- `lib/adapters.mjs`：各平台的只读额度查询及解析。
- `lib/config.mjs`：本机配置、令牌及安全写入。
- `lib/codex.mjs`、`lib/usage.mjs`、`lib/daily-history.mjs`：账户识别、日志统计、历史合并和导入。
- `public/`：原生 HTML、CSS、JavaScript 和本地第三方前端资源。
- `data/`：运行时生成的配置、凭据和历史，不属于发布源码。

## 数据与并发

本进程内的 API 操作与后台归档通过队列串行执行；配置和每日历史写入使用唯一临时文件及替换。此机制不为多个服务进程共享同一个数据目录提供跨进程锁，也不能替代独立备份。缺失的来源显示未配置或历史快照，数据以各来源返回和本机可用记录为准。

## 安全边界

Host 白名单和写入请求的 Origin / Content-Type 检查用于约束网页访问。服务没有本机用户身份验证，同机其他进程仍可访问本地 API；凭据保存在当前用户可访问的本地文件中。详情见 [安全说明](../SECURITY.md)。
