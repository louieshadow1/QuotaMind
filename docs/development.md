# 开发与测试

需要 Node.js 20 或更高版本。运行 `node --test` 执行自动测试；测试使用临时数据及本地模拟服务，不要求配置真实账号。CI 配置列出了 Windows、macOS、Linux 和 Node 版本矩阵；本地测试通过不代表远端 CI 已运行。

前端资源位于 `public/`，服务端入口为 `server.mjs`，数据适配器、配置与存档逻辑位于 `lib/`。启动 `node server.mjs` 后，在浏览器打开本机地址；不要将实际数据目录加入版本控制。

测试包含普通单元与集成测试，以及跨来源请求、异常 URL、并发导入和并发站点写入的回归测试。准备发布时，先检查许可、第三方声明、所有待上传文件和截图，再运行测试与敏感信息扫描。
