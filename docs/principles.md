# 设计原则

1. **集中查看**：在一页查看已配置来源的额度和可获得的用量。
2. **本地优先**：服务和配置保存在用户电脑；查询时向已配置的服务商发送必要请求和凭据。
3. **口径清楚**：区分来源返回、估算值和历史快照；数据缺失或查询失败应可见。
4. **尊重用户数据**：运行时数据不随源码分享；应保留独立备份，不承诺历史永不丢失。
5. **容易开始**：支持三步引导、跳过和重新打开；只需配置正在使用的来源。
6. **安全边界明确**：仅监听本机，限制跨来源写入；不声称能隔离同一电脑的其他程序。
7. **可维护**：原生 Node.js 和浏览器代码，无需构建；用自动测试和回归测试验证关键行为。
